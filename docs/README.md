# 项目文档

这里集中放置不适合充当根目录入口、但属于项目工程资料的文档。

| 目录 | 内容 |
|---|---|
| `data/` | 数据接口和数据接入方案 |
| `operations/` | 日常运行和人工操作流程 |
| `research/` | 研究报告模板 |
| `strategy/` | 策略目标与适配审计 |
| `open_source/` | 面向不同仓库体积目标的 Git 忽略规则 |
| `maintenance/` | 本地维护清单，不属于公开代码入口 |

根目录保留 README、CHANGELOG、依赖清单，以及被验证脚本和历史证据直接引用的核心项目控制文档。
