# 成功与失败案例对照

用户提出从上涨、下跌前的指标变化归纳规律。本轮先在已有E1突破样本中做描述性对照，不声称覆盖所有股票底部或顶部。

在案例统计前固定分类：信号后次日开盘至第10交易日收盘复权变化>5%为上涨组，<-5%为下跌组，其余为中间组，三组全部保留。指标取信号日的MA20距离、突破幅度、量比、ATR占价、20日相对强度、60日趋势R²和大盘20日涨幅。

标签使用未来行情，但特征不能使用未来行情；跨2019/2020边界案例不混入发现期。各年段分别展示中位数与按信号日等权的类别比例，重复/重叠信号不当独立交易。没有训练模型、没有给出预测胜率，也不据两个中位数不同就改实盘规则。此标签与阈值本身尚未做交易盈亏最优化。
