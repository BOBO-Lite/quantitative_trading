## 已核实的候选与口径

微软 Qlib 固定提交 `79633dd9506ea689e5400dea0197717b5b3d74b7`。原文和配置保存在 `github_alpha_review_20260909/`，完整来源见其中 `sources.json`。

CSI300 / Alpha158 表：LightGBM 公布 Annualized Return 0.0901，DoubleEnsemble 0.1158。README 说明为 20 个不同随机种子运行的均值及标准差，并非 20 个独立市场区间。

`examples/run_all_model.py` 第 155—160 行明确取 `1day.excess_return_with_cost.annualized_return`；`qlib/workflow/record_temp.py` 第 507—511 行使用策略日收益减基准日收益再减交易成本。`risk_analysis` 默认按日收益算术累积与均值年化。因此这些数字是扣费年化超额收益统计，不是账户累计收益，也不是账户复合年化；同表回撤也不能直接与我们账户净值最大回撤相比。

LightGBM Alpha158 示例实际条件：沪深300股票池；训练 2008—2014、验证 2015—2016、测试 2017-01-01 至 2020-08-01；初始资金 1 亿元；TopkDropout 持有目标 50 只、n_drop=5；收盘价撮合；买入费率万5、卖出万15、最低5元；涨跌停阈值0.095。没有在该配置中发现本项目真实09:35分钟参与率约束。这里只核实示例配置，未声称重新生成了 README 的历史成绩。

3万元分散50只平均每只600元，与本项目最低4000元、整百股规则不能兼容。改成少量持股后是新策略，必须重测；不能继承上游绩效。测试结束于2020年的示例也不能证明2026年仍有效。

## 对当前项目的判断

RQAlpha 是执行和账户框架，AKShare 是数据接口；它们没有直接解决选股收益。现有 ETF1 完整区间基准成本累计 -1.20%，ETF2 -7.89%，不能与上述超额年化指标排成直接收益排名。黄金/国债 ETF3 范围已获用户批准，目前尚无完成的绩效结果。

当前已核实的制度影响：ETF代码到12%回撤后永久暂停开仓，暂停后即使行情改善也不会恢复；单资产8%冲击损失上限2%意味着名义35%仓位还受到约25%的更紧上限。这会限制资金使用或后续参与，但不能据此断言取消限制就能提高风险调整后的收益。

## 下一步优先级

1. 完成已登记 ETF3 对照，并明确国债一手是否能在预算内成交；不能把研究范围扩大等同于实际分散持仓。
2. 针对用户提出的退出问题，登记一个小规模退出对照研究：固定全部合格入场样本、持仓预算和成本，对比现有保护退出、收盘确认退出及波动率跟踪退出。参数先登记，不能按招商南油一个上涨结果反推最优参数。记录所有样本的收益、最大有利/不利波动、退出后走势，再进行资金约束下完整组合回放。样本不足须报告不足。
3. 分开核算选股质量、退出损益、换手成本、平均仓位与暂停期间错失/规避的市场变动。风险与恢复规则的候选变更只做明确标记的历史研究，不修改实盘。
4. Qlib Alpha158 / LightGBM 留作选股对照候选，先验证少数可解释因子与低换手排序是否有样本外增益，再决定是否承担完整模型训练与数据维护成本。不能先挑收益最高的仓库或反复调参直到历史变好。

上述是研究顺序，不是已验证有效的收益提升幅度。既有框架核账成功、招商南油单例上涨，都不足以证明新模型或退出修改有正期望。
