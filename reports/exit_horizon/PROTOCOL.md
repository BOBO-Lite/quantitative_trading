# FH真实退出原因与固定窗口研究

2026-09-10，在运行本轮结果前登记。

目的：恢复每笔退出最初触发原因，观察同一买点在20/60交易日内继续持有的效果，决定是否有证据进入一项退出改动研究。本阶段不修改实盘或原FH。

1. 用只记录事件的FH子类重新运行2018—2020两档成本。保留每笔持仓第一次返回退出原因的时间、收盘标志、持有天数、止损参考价和前日上下文。原引擎scheduled集合一旦添加不会取消，故第一次退出触发是排队来源；实际硬回撤覆盖仍须从成交原因检查。要求完整结果与已封存FH逐字段一致。
2. 固定原买入的股数、价格、费用和时间。买入当天记第1个交易日，观察第20及60个交易日收盘。持有路径使用已核验现金分红账本，不虚构终点卖出。不足窗口或公司行动未支持时单列。
3. 在同一个窗口末端，只有原退出已经全部成交的案例才计入退出与持有胜负；仍在持仓的案例单列，不使用未来退出收益冒充窗口末收益。原退出后资金保留现金。本轮不将各笔差额相加作为账户收益。
4. 同期市场指数仅为买入日收盘至窗口末收盘的环境对照；与实际盘中买入不同，不能将其差直接称精确超额收益。最高最低日收盘权益只作事后诊断，不能作为下单条件。
5. 两档成本是敏感性对照，不是独立样本。2018—2020已反复使用，不能称盲测。任何有希望的退出改动仍需下一阶段完整组合验证和另行登记；不根据本轮最优样本自动选参数，不取消全部止损。
6. 进入改动研究的最低线索：同一真实原因在20和60日、正常和压力成本下均有正向中位差额，且完成样本不少于5笔。若不满足，报告负面或不确定结论，不强行产生优化版本。即使满足，也先检查年度方向及明显的亏损尾部，再决定候选；只登记一个具有当时可观测条件的改动。
