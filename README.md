
重复记录、源失败或行业覆盖率低于95%都会失败关闭，并保留manifest说明原因。
精简版可让行业时点映射通过，但缺失的上市/退市/交易所元数据会单独令
`point_in_time_universe_metadata_ready=false`，不会被误报为完整股票池元数据。

当前正式导入已通过：104个月无缺失，行业覆盖率97.3583%，股票池元数据
覆盖率100%。`src/build_industry_return_series.py`另生成严格使用前一月末归属的
行业日收益序列，供S2预研究使用；其底层行情仍有当前存续股偏差，因此不是
正式样本外结论。

## SuperMind原生分钟回测

`adapters/supermind_s1_minute_backtest.py`是冻结S1.1的平台适配器。它使用
历史时点股票池和平台真实状态字段，在信号分钟收盘确认后通过
`set_execution('next_open')`撮合，并记录委托、部分成交、成交和撤余单。平台短跑
已验证成交后持仓登记、部分成交加权成本和每标的单一退出委托门禁；适配器还
针对平台在`order()`返回订单号前同步触发回调的行为，改为先登记交易意图再下单。
必须在SuperMind选择股票“分钟”回测，分训练、验证、样本外三段实际运行；
代码文件和本地测试通过不等于回测通过。

2026-09-08三段冻结基线结果为：训练16.21%、验证-1.22%、样本外页面
-9.35%；最大回撤分别为3.15%、8.03%、9.84%。由于验证和样本外均为负，
S1.1状态为`NOT_VALIDATED`，不得提高仓位或接入自动交易。完整证据见
`reports/S1_1_SUPERMIND_ACCEPTANCE_2026-09-08.md`。

平台当前手续费API只能显式设置对称佣金，印花税由引擎自动收取。正式报告
实测卖出印花税为0.10%，高于冻结口径0.05%；当前平台结果只能标记为更保守的
成本压力结果，不能冒充费率完全一致的正式基线。

## 次日只读分钟监视

有研究候选时，可用只读账户快照和已核对财报日历生成“人工决策卡”；程序只读取文件和公开行情，不连接券商、不下单：

```powershell
.\.venv\Scripts\python.exe src\monitor_candidate_minutes.py `
  --candidates reports\daily\YYYY-MM-DD\candidates.csv `
  --account-snapshot data_templates\account_snapshot.json `
  --event-calendar data_templates\periodic_report_calendar.csv `
  --output reports\daily\YYYY-MM-DD\minute_monitor.json
```

账户快照必须带时区且生成不超过15分钟；财报日历必须在7天内核对并覆盖入场日起未来31天。缺文件、过期、覆盖不足或持仓期内有定期报告时均不生成可执行数量。模板只是格式示例，使用前必须换成当日可信数据。

## 当前不可越过的边界

- 当前主板搜狐历史日线已通过预回测质量门槛，月末时点股票池/行业也已完整导入；但本地仍缺逐日ST、停牌、涨跌停和完整分钟数据，因此没有正式PF、胜率或回撤结论；
- SuperMind原生适配器用于让平台在回测时提供逐日状态和分钟撮合；必须实际编译、运行并保存报告后才能生成正式结论；
- 未验证阶段不允许融资、杠杆、界面自动点击下单或交易卡外临时加量。
- S1.1的U0实盘上限仍为70%；S2研究版只在有利环境把目标仓位提高到90%，单笔风险保持1.25%，未通过样本外验收前不自动替代S1。
